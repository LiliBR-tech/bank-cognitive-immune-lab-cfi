
# Customer Feedback Intelligence (CFI)

## Desafio Criativo — Extraindo Insights do Feedback de Clientes Bancários

O **Customer Feedback Intelligence (CFI)** é um experimento de Inteligência Artificial aplicado à análise de feedbacks de clientes em contexto bancário, desenvolvido a partir do desafio de construção de um prompt estruturado.

O objetivo é orientar uma IA na identificação de temas, padrões, problemas e oportunidades a partir dos dados fornecidos, utilizando contexto, critérios de análise e cuidados relacionados à proteção de informações pessoais ou sensíveis.

## Objetivo

Investigar como a definição estruturada de **intenção, contexto, critérios e restrições** pode orientar uma IA na transformação de feedbacks de clientes em informações organizadas e úteis para análise.

O resultado deve:

* identificar temas recorrentes;
* classificar sinais relevantes dos feedbacks;
* apresentar evidências presentes nos dados;
* indicar possíveis oportunidades de melhoria;
* informar limitações quando os dados não forem suficientes;
* evitar a criação de informações não presentes na base analisada.

## Construção do Prompt

O prompt foi desenvolvido de forma incremental, seguindo as etapas propostas pelo desafio:

### 1. Intenção

Definição do que a IA deve analisar, para qual finalidade e qual resultado se espera obter.

### 2. Contexto e Restrições

Definição do contexto bancário, dos dados disponíveis, dos critérios de análise e dos cuidados necessários no tratamento das informações.

### 3. Refinamento

Consolidação das etapas anteriores em um único prompt estruturado, com instruções sobre análise, evidências, formato da resposta e limitações.

## Critérios do Experimento

O prompt estabelece que a IA deve:

* utilizar exclusivamente os dados fornecidos;
* não inventar números, causas ou conclusões;
* não expor dados pessoais ou sensíveis;
* diferenciar evidências de interpretações;
* indicar quando os dados não forem suficientes;
* produzir uma resposta organizada e orientada à análise.
